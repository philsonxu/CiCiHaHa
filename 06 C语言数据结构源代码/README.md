# C语言数据结构源程序库

完整的严蔚敏《数据结构（C语言版）》教材覆盖实现，每个数据结构都包含独立API和完整验证测试。

## 📂 目录结构

```
c_datastructures/
├── include/         # 头文件（公共头 + 各数据结构API声明）
│   ├── common.h         公共类型/状态码/工具宏
│   ├── seqlist.h        顺序表
│   ├── linklist.h       单链表（含反转/倒数K/环检测）
│   ├── stack.h          顺序栈 + 括号匹配/中缀转后缀/表达式求值
│   ├── queue.h          循环队列 + 链式队列
│   ├── string_ds.h      串 + BF/KMP/nextval
│   ├── bitree.h         二叉树 + BST二叉搜索树
│   ├── graph.h          邻接矩阵/邻接表 + BFS/DFS/Dijkstra/Floyd/Prim/拓扑排序
│   ├── search.h         顺序/二分/插值查找 + 链地址法散列表
│   └── sort.h           十大排序 + 性能基准
├── src/             # 实现源码（一一对应头文件）
├── tests/           # 验证测试程序
│   ├── test_*.c         各模块独立测试
│   └── test_all.c       汇总入口，一键跑完所有测试
└── Makefile
```

## 🧪 一键编译运行

```bash
make            # 编译
make run        # 运行全部验证测试
make clean      # 清理
```

## ✅ 涵盖的核心内容

| 类别 | 数据结构/算法 |
|------|--------------|
| **线性表** | 顺序表（动态扩容）、单链表（头插/尾插/反转/Floyd判圈/倒数K节点） |
| **栈** | 顺序栈、括号匹配、中缀→后缀表达式、后缀表达式求值 |
| **队列** | 循环队列（取模）、链式队列（带头尾指针） |
| **串** | HString堆分配串、BF朴素匹配、KMP算法（next/nextval优化） |
| **树** | 二叉树（先/中/后/层序遍历、深度/叶子/复制）、BST二叉搜索树（插入/删除/查找） |
| **图** | 邻接矩阵、邻接表、DFS、BFS、Dijkstra单源最短路径、Floyd全源、Prim最小生成树、拓扑排序 |
| **查找** | 顺序查找（哨兵优化）、折半查找、插值查找、链地址法散列表 |
| **排序** | 直接插入、折半插入、希尔、冒泡（提前结束）、快排（三数取中）、简单选择、堆排序、归并排序、基数排序LSD |
