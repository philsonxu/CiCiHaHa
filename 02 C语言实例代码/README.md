# 谭浩强《C语言程序设计》（第五版）实例源程序集

本套源码按照谭浩强《C语言程序设计》（第五版）教材章节组织，覆盖全书核心知识点，每个程序都有详细注释说明所涉及的知识点，适合初学者上机练习与复习。

## 编译运行方法

使用gcc编译单个源文件：
```bash
gcc -o 程序名 源文件名.c
./程序名
```

例如：
```bash
gcc -o ex5_12 ex5_12_斐波那契数列.c
./ex5_12
```

Windows下可使用 Dev-C++、Code::Blocks、Visual Studio 等IDE打开.c文件直接编译运行。

## 学习建议

1. **逐章练习**：按章节顺序学习，不要跳读，指针和数组是重点也是难点，需要多动手。
2. **先读再敲**：先阅读代码和注释理解思路，再自己独立敲一遍，不要直接复制粘贴。
3. **修改调试**：在看懂的基础上修改参数、增加功能，尝试故意制造错误观察编译/运行结果。
4. **独立完成课后题**：本文件集是教材例题的配套实现，课后习题要独立完成。
5. **善用调试**：学会使用IDE的断点调试功能，观察变量在每一步的变化。
