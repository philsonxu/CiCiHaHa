# C语言数值计算源代码集

一套完整的C语言经典数值计算算法实现，**全部算法均配有可运行的验证程序与标准测试数据**，适合学习数值分析、科研计算或工程项目集成。

## 目录结构

```
c_numerical_computing/
├── common/                    # 公共工具模块
│   ├── common.h / common.c    # 矩阵向量结构、打印、误差计算、文件IO、计时
│
├── 01_matrix_basics/          # 第1章 矩阵基础运算
│   ├── matrix_ops.h/c         # 加减乘、转置、行列式、LU分解(部分选主元)、矩阵求逆
│   ├── test_matrix.c          # 验证程序：内置3x3 + 文件读取4x4 + 200x200性能
│   └── test_data/mat4x4.txt   # 4x4对称正定矩阵测试数据
│
├── 02_linear_solver/          # 第2章 线性方程组 Ax=b 求解
│   ├── linear_solver.h/c      # 高斯消元、雅可比迭代、高斯-赛德尔、共轭梯度(CG)
│   ├── test_linear.c          # 验证：3x3教材用例、2500阶泊松矩阵、Hilbert病态矩阵
│   └── test_data/             # Hilbert 10阶矩阵（经典病态系统）测试数据
│
├── 03_root_finding/           # 第3章 非线性方程求根
│   ├── root_finding.h/c       # 二分法、牛顿法、割线法、不动点迭代
│   └── test_root.c            # 验证：x²-2、cos(x)=x(Dottie数)、x³-x-2=0
│
├── 04_numerical_integration/  # 第4章 数值积分
│   ├── integration.h/c        # 复合梯形、复合辛普森、自适应辛普森、龙贝格、高斯-勒让德
│   └── test_integration.c     # 验证：x²、sin(x)、e^x、π逼近、√x(端点奇异)
│
├── 05_interpolation/          # 第5章 插值与逼近
│   ├── interpolation.h/c      # 拉格朗日、牛顿差商、三次样条(自然边界)
│   ├── test_interpolation.c   # 验证：Runge现象演示、切比雪夫节点、sin(x)5点插值
│   └── test_data/             # sin(x)等距采样点
│
├── 06_ode_solver/             # 第6章 常微分方程初值问题
│   ├── ode_solver.h/c         # 显式欧拉、改进欧拉、经典RK4、自适应RK45(Dormand-Prince)
│   └── test_ode.c             # 验证：y'=-y、y'=y、y'=cos(t)
│
├── 07_least_squares/          # 第7章 最小二乘拟合
│   ├── least_squares.h/c      # 多项式最小二乘拟合（正规方程+高斯消元）、R²评价
│   ├── test_lsq.c             # 验证：精确二次、带噪声线性、文件读取100点噪声二次
│   └── test_data/             # 100点带噪声二次函数数据
│
└── 08_eigenvalue/             # 第8章 特征值计算
    ├── eigenvalue.h/c         # 幂法、反幂法、Jacobi旋转法（对称矩阵全部特征值）
    └── test_eigen.c           # 验证：3x3解析可解矩阵、4x4对称矩阵全特征值+残差检验
```

## 编译运行

```bash
# 一键编译全部8个验证程序（依赖gcc、make、libm）
make

# 一键运行全部验证测试
make run

# 或单独运行某个章节
cd 01_matrix_basics && ./test_matrix
cd 04_numerical_integration && ./test_integration

# 清理编译产物
make clean
```

## 算法覆盖

| 类别 | 算法 | 精度/阶 |
|------|------|---------|
| 矩阵运算 | 矩阵加减乘、转置、行列式、LU分解（部分选主元）、矩阵求逆 | O(n³) |
| 线性方程组 | 高斯消元法（直接法）、雅可比迭代、高斯-赛德尔迭代、共轭梯度法(CG) | CG适用于大规模稀疏对称正定系统 |
| 非线性求根 | 二分法（线性收敛）、牛顿法（二次收敛）、割线法（超线性1.618）、不动点迭代 | - |
| 数值积分 | 复合梯形(O(h²))、复合辛普森(O(h⁴))、自适应辛普森、龙贝格积分(Richardson外推)、高斯-勒让德求积 | 5点高斯精度达O(h^10) |
| 插值 | 拉格朗日插值、牛顿差商插值、三次样条插值（C²连续自然边界） | 演示Runge现象与切比雪夫节点 |
| 常微分方程 | 显式欧拉(O(h))、改进欧拉Heun(O(h²))、经典RK4(O(h⁴))、自适应RK45(Dormand-Prince embedded pair) | 自适应步长控制误差 |
| 最小二乘 | 多项式拟合（正规方程法）、R²决定系数评价 | 支持任意阶数多项式拟合 |
| 特征值 | 幂法求最大模特征值、反幂法求最小模特征值、Jacobi旋转法求对称矩阵全部特征值与特征向量 | 含A·v = λv残差验证 |

## 设计特点

1. **完整可验证**：每个算法均配有理论精确解对比，输出PASS/FAIL与误差量级
2. **自带测试数据**：矩阵、Hilbert病态系统、噪声采样等标准测试数据以文本格式存于`test_data/`目录，可被任何语言读取
3. **无外部依赖**：纯C99/C11实现，仅依赖标准库（libm），可在Linux/macOS/Windows（MinGW）直接编译
4. **代码规范清晰**：每个模块严格区分头文件（.h）与实现（.c），关键算法带有中文注释说明步骤与数学原理
5. **公共工具库**：统一的Matrix/Vector结构、文件读写、打印、误差计算、计时工具，避免重复造轮子
6. **教学友好**：既展示算法原理（如高斯消元、LU分解逐过程），也展示工程实践（部分选主元、自适应步长、残差验证）

## 使用建议

- 初学者可按章节顺序阅读，从矩阵运算、线性方程组入手逐步深入
- 工程使用者可直接拷贝对应算法.c/.h文件集成到项目中（同时需拷贝common公共模块）
- 测试数据文件为纯文本格式（首行为维度，后续为数据），可自行替换为自己的数据集测试
