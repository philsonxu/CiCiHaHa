【运行环境】
- Turbo C 2.0 / 3.0
- DOSBox (推荐在现代系统上通过DOSBox运行)
- 需要BGI图形驱动(EGAVGA.BGI)

【编译运行方法】
1. 将所有.c文件复制到Turbo C目录下
2. 启动Turbo C，打开对应源文件
3. 按F9编译，Ctrl+F9运行
4. 注意：initgraph中的BGI路径需根据实际安装位置修改
   默认路径为 "C:\\TC\\BGI"，如安装在其他位置请自行修改

【BGI路径配置】
如果你的Turbo C安装在D盘TC目录下，请将程序中：
   initgraph(&amp;gd, &amp;gm, "C:\\TC\\BGI");
改为：
   initgraph(&amp;gd, &amp;gm, "D:\\TC\\BGI");

或者使用自动查找：
   initgraph(&amp;gd, &amp;gm, "");

【操作说明】
- 大多数动画程序按任意键退出
- 图形窗口分辨率为640x480(VGAHI模式)
- 坐标系原点(0,0)在左上角，x向右增加，y向下增加
